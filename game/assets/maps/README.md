# Pyrrhia atlas assets

`pyrrhia_coast.svg` is simplified geometry from the existing stage-1 land mask,
regenerated by `tools/map/prepare_overworld.py`. Kingdom label positions are in
`game/data/overworld_labels.json` and come from the repository's hand-authored
map annotations. These share a cropped 2165 × 1606 coordinate system.

The optional **ignored** `pyrrhia_reference.png` is the cropped original
*Wings of Fire* Pyrrhia map, restored 2026-11-13 from the wiki:

- File: https://wingsoffire.fandom.com/wiki/File:PyrrhiaColored.png
- Download endpoint: https://images.wikia.com/wingsoffire/images/e/e3/PyrrhiaColored.png

The illustration is third-party book reference art; no new license or ownership
is claimed. It stays outside version control under the existing public-repository
source-art policy. Game exports exclude it. The runtime draws native vector geometry from
`game/data/pyrrhia_coast.json` with `game/scripts/vector_atlas.gd`; this SVG is a
source preview only. See `docs/overworld-map.md` for regeneration.
