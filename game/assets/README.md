Place the generated local `clay.glb` here. See [the game setup guide](../README.md).
GLB files are ignored by Git. This folder can also hold future committed assets
that are appropriate for this public repository.


The anatomical children and Umber's gathered leather pouch are generated under
`scavengers/`. Fetch and build them using `tools/fetch_human_source.py`,
`tools/fetch_hair_source.py` and `tools/build_scavengers.py` (see the game guide).
The hair meshes and textures have their own [credits](scavengers/CREDITS.md).
